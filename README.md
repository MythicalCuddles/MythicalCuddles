## About Me

Hi! I'm **Melissa**, also known online as **MythicalCuddles**.

I enjoy turning ideas into working projects - whether that's a small game, a piece of automation, a Discord bot, a web application, or something built for VRChat.

A lot of my projects begin with a simple:

> *"I wonder if I can make that..."*

...and usually end with significantly more code than originally planned.

My interests currently sit around **software development, game development, automation, community tooling and interactive experiences**.
